Codelab — Building & Shipping Agents

Managing the Agent Lifecycle

The hands-on companion to the series: how to scaffold, test, and deploy production agents from the terminal using Google's Agents CLI and ADK 2.0 — without learning a new SDK.

Google DevelopersAgents CLI + ADK 2.0· Codelab
Open the codelab →

If the Day-1 whitepaper makes the case that the developer's job is now designing the system that builds software, this codelab is where you actually build one. It walks through the complete local development lifecycle of an AI agent using Google's Agents CLI and the Agent Development Kit (ADK 2.0) — part of Kaggle's five-day intensive with Google.

01One install, seven skills

The setup is a single command — uvx google-agents-cli setup — which installs the CLI globally and deploys seven domain-specific coding-assistant skills to ~/.agents/skills/. Crucially, it doesn't ask you to learn a new SDK: the skills attach to whichever coding agent you already use (Claude Code, Codex, and others), which then does the right thing at each step. Authentication runs through either a Gemini API key from Google AI Studio or Google Cloud credentials for Vertex AI deployment.

02Agents as graphs

ADK 2.0 models an agent application as a graph workflow. A Workflow and its edges orchestrate the flow; LlmAgent nodes handle language-model tasks; Python @node decorators wrap custom logic; and conditional routing branches on classification results. The codelab builds a customer-support agent to make the pattern concrete — a router that classifies an incoming request and sends it down the right path.

Describe what you want; the coding agent uses the skills to scaffold, code, evaluate, and deploy — no new framework to learn.

03A live local playground

Development happens in an interactive playground: a chat interface where you talk to your agent and inspect tool executions in real time, with automatic code reloading as you edit. Automated code-quality checks run alongside. The stack is deliberately lightweight — Python 3.11+, Node 18+, the uv package manager, Gemini models, and the Antigravity IDE for assisted development.

04From laptop to production

The same workflow that produces a prototype produces the production agent. The codelab closes by pointing at the next steps that turn a local experiment into a real service: structured evaluation, cloud deployment to Agent Runtime, and production observability through Cloud Trace and BigQuery — the substrate the Day-1 paper insists you build before scale, not after.
